# Agent Note: Port the floating orb onto dsh 0.1.7

Status: implemented

English | [中文](2026-09-24-orb-on-dsh-0.1.7.zh.md)

## Problem

The floating orb and Computer Use work was branched from dsh on 2026-09-10. Official `dsh-v0.1.7-rc.1` replaced the desktop Host pipe, directory Agent presets, and client Session selection. A textual merge of that branch cannot keep both the official desktop and the orb.

## Decision

`orb/on-dsh-0.1.7` starts at official `master` and merges the orb branch once. Official desktop, LLM image handling, and generated docs stay. The orb is reattached on the current Host:

- Electron and the Desktop Host exchange overlay-guard, observation-frame, and capture acks with `process.send`. The old request pipe is not restored.
- The Computer Use agent is an `@deepseek-ai/dsh-agent-preset` row inserted by `packages/experimental/tool-computer-use/cordis.patch.yml`. Desktop loads that file when `DSH_COMPUTER_USE_PATCH` points at it.
- Overlay Compact Chat retains its Session with `sessions.retain(..., { source: 'mainView' })` inside the overlay document. It does not call the removed `sessions.open`.
- `ui-settings-orb` and `ui-overlay-chat` are rows in the web-app bundle. Host orb plugins mount with `ctx.plugin` after the desktop profile boots.

Coordinate-mode still reads Session history with `snapshotEvents`. That read is the existing one and is marked deferred, matching other unmigrated callers.

## Alternatives considered

**Rebase the 88 orb commits onto official master.** The same desktop files conflict on many commits. One merge resolves each file once.

**Keep the September 10 desktop Host and pipe protocol.** That drops official Windows packaging, updates, and the current profile boot.

**Load Computer Use through the official `dsh-computer-use` provider seam now.** That seam allows one provider. Re-homing the orb driver is separate from making this branch run.

## Consequences

Mac and Windows development use `pnpm run dev:desktop` on this branch. Packaging stays on the existing scripts and is not part of this port. Official Computer Use providers must not be enabled in the same desktop profile as this experimental preset.
