# Agent Note: 把悬浮球接到 dsh 0.1.7

Status: implemented

[English](2026-09-24-orb-on-dsh-0.1.7.md) | 中文

## Problem

悬浮球和 Computer Use 在 2026-09-10 从 dsh 分出。官方 `dsh-v0.1.7-rc.1` 换掉了桌面 Host 管道、目录式 Agent 预设，以及客户端 Session 选择。把该分支按文本合并进来，不能同时留下官方桌面和悬浮球。

## Decision

`orb/on-dsh-0.1.7` 从官方 `master` 开始，只合并悬浮球分支一次。官方桌面、LLM 图片处理和生成文档保留。悬浮球接到当前 Host 上：

- Electron 和 Desktop Host 用 `process.send` 交换 overlay-guard、observation-frame 和截图应答。旧的请求管道不恢复。
- Computer Use agent 是 `@deepseek-ai/dsh-agent-preset` 的一行，由 `packages/experimental/tool-computer-use/cordis.patch.yml` 插入。Desktop 在 `DSH_COMPUTER_USE_PATCH` 指向该文件时加载它。
- Overlay Compact Chat 在 overlay 文档里用 `sessions.retain(..., { source: 'mainView' })` 保留 Session。它不调用已删除的 `sessions.open`。
- `ui-settings-orb` 和 `ui-overlay-chat` 是 web-app bundle 里的行。Host 上的悬浮球插件在 desktop profile 启动后用 `ctx.plugin` 挂上。

坐标模式仍用 `snapshotEvents` 读 Session 历史。这是既有读取，标成延期，和其他尚未迁移的调用方一致。

## Alternatives considered

**把 88 个悬浮球提交逐个 rebase 到官方 master。** 同一批桌面文件会在多个提交上冲突。一次合并每个文件只解一次。

**保留 9 月 10 日的桌面 Host 和管道协议。** 那会丢掉官方的 Windows 打包、更新和当前的 profile 启动。

**现在就把 Computer Use 接到官方 `dsh-computer-use` 提供方接缝。** 该接缝同时只允许一个提供方。把悬浮球驱动改挂上去，和让这个分支先跑起来是两件事。

## Consequences

Mac 和 Windows 开发环境在这个分支上用 `pnpm run dev:desktop`。打包仍用现有脚本，不属于这次移植。同一 desktop profile 里不能同时启用官方 Computer Use 提供方和这个实验预设。
