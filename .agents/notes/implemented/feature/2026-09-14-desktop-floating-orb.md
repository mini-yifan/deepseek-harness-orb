# Agent Note: Desktop floating orb and dual Agent

Status: implemented

English | [中文](2026-09-14-desktop-floating-orb.zh.md)

## Problem

Computer Use is an experimental overlay that a Web `--patch` can mount, but Desktop packaged the Web UI as one main window with the `standard` default. A user who wants GUI control and background coding from the same desktop shell would otherwise get a second Web client, a mode picker on a compact overlay, or a `tool-subagent` child that the sidebar hides.

## Decision

macOS Desktop creates a second Electron overlay after Host ready: a 72px always-on-top ball in a transparent panel window that loads `dsh-app://shell/floating.html` through the existing shell preload. The default image is the packaged GIF; [Desktop orb Settings](2026-09-18-desktop-orb-settings.md) can replace it with a profile GIF, PNG, or WebP. The page fetches the same Host `/api` as the main window. The overlay document is not `dsh-app://app/index.html`. `#transcript` hosts an iframe of `dsh-app://app/index.html?surface=overlay` that mounts Compact ChatView; [overlay Compact ChatView](2026-09-16-overlay-compact-chat.md) owns that nested surface. Windows keeps today's single main window. Cold start places the collapsed 72px ball on the primary-display work-area right edge, 8% of that height below vertical center; `defaultFloatingBallOrigin` computes that origin. Drag does not persist it.

The overlay session calls `session.create({ agentPreset: 'computer-use', workspaceId })` after `workspace.create` on `$DSH_HOME/dsh_orb` (sidebar title `dsh_orb`) and applies the stored overlay model from `orb-agent-models.json` (shipped default `deepseek-flash` at `max`) with `saveAsDefault: false`; [floating-ball Agent model menus](2026-09-17-orb-agent-model-menus.md) owns those menus and the background `code_agent` create path. Desktop Host pins the live overlay Access preset (shipped default `danger-full-access`) on Computer Use and standard sessions whose cwd is `dsh_orb`; [overlay Access picker](2026-09-17-overlay-access-picker.md) owns the header chip, `orb-permission.json`, and overlay-send `/permission` reapply. The active overlay id is stored in the Desktop profile as `floating-session.json`. The main window keeps its current session; overlay sessions and `code_agent` rows whose cwd matches that workspace appear under `dsh_orb`. SessionHeader origin is unchanged.

The overlay is one 72px ball that hover-expands a 320×420 panel that follows Host Appearance (300ms) while the ball stays in the input-pill corner. Click pins the panel; click again unpins, and the pointer leaving both then collapses after 180ms. Unpinning while the pointer remains on the overlay leaves the panel expanded. During collapse the ball stays in its expand corner until the window shrinks to the collapsed chrome size. [Floating-orb CSS shadow and pin stroke](2026-09-17-floating-orb-chrome-shadow.md) owns the 12px window inset, drop shadows, hairline, and outer pin stroke. Primary-button drag records the pointer offset against the ball, collapses immediately, and moves by ball origin so stored expand direction cannot slide the ball; [floating-orb primary pointer drag](../bug-fix/2026-09-17-floating-orb-primary-pointer-drag.md) owns which buttons start that grab. Clamp on pointerup keeps a free-floating ball inside the work area; left/right edge dock is [floating-orb edge dock](2026-09-20-floating-orb-edge-dock.md). The composer wraps around the ball and grows toward the transcript; Enter sends and Shift+Enter inserts a newline ([overlay growing composer](2026-09-19-overlay-growing-composer.md)). Stop is a body sibling (`#ball` z-index 1, `#stop` z-index 2) at the opposite end of the input pill from the ball and shows only while the Computer Use session is running, replacing the hidden input; a click calls `session/cancel` for that overlay session. A History control replaces the Compact transcript iframe with Computer Use sessions whose cwd is `dsh_orb` and whose projected preset is `computer-use`; delegated standard and `code_agent` rows stay out of that list. History and New sit on the transcript edge opposite the input pill; [overlay History and New follow the input-pill edge](../bug-fix/2026-09-17-overlay-history-new-follow-expand.md) owns that placement. An Access chip sits between them; [overlay Access picker](2026-09-17-overlay-access-picker.md) owns that control. A click adopts that id into `floating-session.json` and posts it into the iframe so further prompts continue that chat. A New control mints another Computer Use session on `dsh_orb`. When that Computer Use session raises `ask_user_question`, the overlay claims the live `'user-questions/request'` waterfall and renders a compact answer card in the expanded panel; [floating orb user questions](2026-09-15-floating-orb-user-questions.md) owns that Client path.

`code_agent` is registered only on the Computer Use preset. Create uses `session.create({ agentPreset: 'standard' })` with no `origin: 'subagent'` and no `parentAgent`. Desktop create applies optional `orbCodeAgentModel` before prompt; continue does not. Prompt uses `mode: 'queue'` and returns `{ accepted: true }` without waiting for the turn. A Computer Use-owned watch later parks a plugin notice until both sessions are idle; [Computer Use parks Code agent completion](2026-09-15-computer-use-code-agent-completion.md) owns that delivery. Omit `session_id` to mint a blank standard session; pass the previous result id to enqueue another user message on that session. [Overlay Computer Use background dispatch](2026-09-17-orb-code-agent-dispatch.md) owns create cwd, the caller-owned registry, `code_agent_status` / `code_agent_stop`, and unattended answerers on the Code agent. The Computer Use policy tells the model to keep visible GUI on the GUI tools, send long work to `code_agent`, keep short lookup on web tools, continue the same artifact with the prior id, start unrelated work without an id, tell the user the background agent is running and end the turn, and report a later plugin notice.

Desktop Host overlay YAML inserts `computer-use-preset-root` from `../lib/computer-use-preset-root.js`, `computer-use-overlay-guard` from `../lib/computer-use-overlay-guard.js`, `computer-use-orb-permission` from `../lib/computer-use-orb-permission.js`, and `computer-use-orb-code-agent-model` from `../lib/computer-use-orb-code-agent-model.js`, and keeps `default: standard` with mode selection enabled. `prepare-dsh` copies `@deepseek-ai/dsh-experimental-tool-computer-use` into `extraResources/dsh` as a runtime extra and rewrites the preset composition to `lib/*.js`. Release apps still must not name the experimental package in `dependencies`. The main window stays capturable. The overlay is capture-excluded through ScreenCaptureKit `excludingWindows` and click-through only for the matching Computer Use interval; see [Desktop overlay guard](../architecture/2026-09-14-desktop-overlay-guard.md). The overlay stays on every Space and above fullscreen with `setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true, skipTransformProcessType: true })`. After creating the overlay, Desktop calls `app.setActivationPolicy('regular')` and `app.dock.show()` so the Dock icon remains. The application menu includes the standard Edit and Window menus. Overlay right-click adds cut/copy/paste when the target is editable, plus nested Floating Agent Settings and Background Agent Settings.

The [Computer Use plugin decision](2026-09-13-experimental-computer-use.md) remains the owner of GUI tools, policy text, and the experimental consent gate.

## Alternatives considered

**A second packaged Web client as the overlay document.** Loading `dsh-app://app/index.html` as that document would boot the full client, including the mode picker the compact ball must not show. The shell page stays `floating.html`; Compact ChatView loads in a transcript iframe.

**Lock the Desktop profile default to `computer-use`.** That would force the main window onto Computer Use. Overlay create names the preset; the shipped default stays `standard`.

**`tool-subagent` for background coding.** Sidebar filters `origin: 'subagent'`, and `session.prompt` rejects those ids. Delegated work must be a first-class standard session.

**A new SessionHeader origin for the orb.** That would bump `SESSION_FORMAT_VERSION` for a Desktop-only grouping. Membership on the `dsh_orb` workspace is enough.

**Declare the experimental package as a Desktop Host dependency.** Experimental AGENTS.md forbids release apps from naming it. The runtime extra copy is the exception; the locator lives in Desktop Host.

**Windows overlay in this cut.** The ball is macOS `type: 'panel'` plus `setVisibleOnAllWorkspaces` with `skipTransformProcessType`. Windows stays one window.

**Leave Electron's implicit centered window.** That places the ball in the middle of the user's work. Cold start uses the primary-display work-area right edge, 8% of that height below vertical center.

**Place Stop on the ball.** That covers the GIF and shares the drag/pin corner. Stop sits in the opposite 72px cap of the pill, 14px inset, as a body sibling so it paints above the pill.

## Consequences

Closing the main window on darwin leaves the ball running until an explicit Quit from the Dock, Cmd+Q, or the overlay context menu. The overlay has no voice, lasso, or per-click approval. [Desktop selection toolbar](2026-09-16-desktop-selection-toolbar.md) owns Search / Translate after a drag-select, and [Desktop selection Send to Agent](2026-09-17-desktop-selection-send-to-agent.md) owns the third toolbar button. The overlay is a second Gateway Client for live `'user-questions/request'` waterfalls on Computer Use sessions it holds, so a closed main window still has an answerer. Overlay capture exclusion and click-through are scoped to Computer Use intervals; capture omit uses ScreenCaptureKit window ids for visible overlay windows. Restart resumes the stored Computer Use session when Host still holds it. Overlay Computer Use cwd is `$DSH_HOME/dsh_orb`. Snapshot and package tests pin `code_agent` routing examples (WeChat/Pages GUI, Word create, font-green continue, gobang new session) and the macOS-only overlay construction.

## Testing

Desktop copies the runtime extra and keeps overlay YAML on `default: standard`. Desktop Host tests pin orb Computer Use and standard on `dsh_orb` to the live overlay Access preset and leave Computer Use on another workspace at the Host default. Computer Use package tests cover `code_agent` create without subagent origin, omit-cwd subdirectory create, continue by `session_id` only for this caller, reject CU/subagent/cwd mismatch and foreign ids, two `user/message` events on the continued session versus a new session when the id is omitted, parked completion notices that wait for both sessions to go idle, and `code_agent_status` / `code_agent_stop`. The computer-use snapshot overlay stubs `sessionController` so the header pin includes the `code_agent*` schemas. Client tree tests still omit ids supplied as `hiddenSessionIds` and keep the delegated standard row. Electron tests create a `type: 'panel'` overlay on darwin, skip it off darwin, leave both windows capturable by default, pass `skipTransformProcessType: true`, and call `app.setActivationPolicy('regular')` plus `app.dock.show()` after overlay create. They also pin the application Edit menu, overlay editable-field paste items, `defaultFloatingBallOrigin` on a work-area right edge slightly below center, overlay construction at that origin, expand bounds that keep the ball origin, expanded `moveFloatingBall` without panel clamp, work-area clamp that does not dock a flush ball, and left/right dock when one-third of the ball sits past the display edge. The overlay renderer creates the `dsh_orb` workspace, creates the Computer Use session over Host RPC, selects the stored overlay model (shipped default DeepSeek-V41-Flash at Max) with `saveAsDefault: false`, sends on Enter, places Stop at the opposite pill end from the ball, shows Stop after a prompt and calls `session/cancel` on click, drags with the ball grab offset after collapse, ignores a secondary-button press and a hover after the primary button is up, keeps the panel expanded when unpinning while the pointer is still on the ball, lists only `dsh_orb` Computer Use chats from History (omitting delegated standard rows), adopts a selected id for further prompts, mounts Compact ChatView in a `?surface=overlay` iframe, and claims live `'user-questions/request'` waterfalls for those sessions so the compact card can answer or `next()`.
